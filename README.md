geno.numerical.csv contains the numerical genomic information of the recombinant inbred lines (RILs), used to compute the genomic relationship matrix (GRM) for prediction models.

Phenomic_ExR_NGRDI.csv contains NGRDI and ExR vegetation indices measured at earlier time points — 43, 57, 62, 65, 69, 72, 76, 79, and 83 days after planting (DAP) — prior to the onset of senescence. These phenomic features were used to construct the phenomic relationship matrix (PRM) for prediction models.
